# Bedrock Drowned Mechanics

# How it works
Now, when a zombie turns into a drowned, all its armor drops with maximum durability, and there is a configurable chance of obtaining a trident and a nautilus shell.


## Gamerule commands



```
/gamerule nautilus_shell_spawn_chance <float>
```

- Sets the chance of a nautilus shell appearing (Vanilla chance 3.0%)


```
/gamerule nautilus_shell_drop_chance <float>
```
- Sets the chance of a nautilus shell dropping (Vanilla chance 100.0%)

```
/gamerule trident_spawn_chance <float>
```
- Sets the chance of a trident appearing (Vanilla chance 6.25%)

```
/gamerule trident_drop_chance <float>
```
- Sets the chance of a trident drop (Vanilla chance 8.5%)

```
/gamerule random_armor_durability <boolean>
```
- Turns off and turns off the random durability of dropped armor (Default false)

```
/gamerule random_trident_durability <boolean>
```
- Turns off and turns off the random durability of trident (Default true)
